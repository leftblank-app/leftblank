LeftBlank adaptation

The bundled guide adapts the drawing workflow and conventions of:
https://github.com/enesozturk/dimensional-drawing
Pinned reference: 5c457437c8c83524308aad3b7443e81adcc13153

LeftBlank provides newly written native Typst starter code and example concept
geometry. The original HTML/SVG renderer and animation code are not included.
Example values are illustrative design assumptions, not measurements of an
existing product. Attribution does not imply the original author's endorsement.
