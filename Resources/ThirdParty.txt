LeftBlank uses the following bundled components:

Tinymist v0.15.8 (MIT)
https://github.com/Myriad-Dreamin/tinymist/tree/v0.15.8
The Mac helper is built from that tag with LeftBlank's patches (native TLS, VFS fix).
Binary contains Typst 0.15.1 (Apache-2.0), from Tinymist's pinned upstream fork.
https://github.com/Myriad-Dreamin/typst/tree/tinymist/v0.15.1
See Tinymist-LICENSE and Typst-LICENSE.
The iPad engine embeds Typst assets 0.15.1 fallback fonts; their notices and
licenses are in Licenses/typst-assets-NOTICE.txt.

Noto Sans SC variable font (SIL Open Font License 1.1)
https://github.com/google/fonts/tree/9710da1eacb3be272583c3224dcb70f9da6eadbb/ofl/notosanssc
Portable Chinese fallback shared by Mac and iPad; existing fonts stay first in template font lists.
Font and original license are bundled in LeftBlankCore Resources/Fonts.
SHA-256: a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da

Phosphor Icons Regular (MIT)
https://github.com/phosphor-icons/core/tree/2b75f3ad12b420c9504ef05df8d2564a28f8500e
SVG source icons converted to vector PDF using librsvg for AppKit and UIKit.
See Phosphor-LICENSE.

App icon is an original LeftBlank vector mark (AppIcon.svg): a continuous ivory capital Sigma on charcoal, generated by design/sigma/generate.py using golden-ratio geometry and a sine pressure envelope. No third-party logo artwork or font outlines are used in the mark.
Nano Emacs and Spacemacs inspired the visual and command-discovery design;
no source code from either project is bundled.

Code notes includes codly 1.3.0 and codly-languages 0.1.1 (MIT).
https://typst.app/universe/package/codly/
https://typst.app/universe/package/codly-languages/
Original license notices and package contents are in Packages/preview/.
Archive provenance and checksums are in Packages/README.md.

Highlight.js 11.11.1 common language bundle (BSD-3-Clause)
https://github.com/highlightjs/cdn-release/blob/11.11.1/build/highlight.min.js
Bundled in LeftBlankCore resources and run offline through JavaScriptCore for code-block colors.
SHA-256: c4a399dd6f488bc97a3546e3476747b3e714c99c57b9473154c6fb8d259b9381
The original license is bundled as highlightjs-LICENSE in LeftBlank_LeftBlankCore.bundle.

Additional Highlight.js 11.11.1 Scheme grammar (BSD-3-Clause)
https://github.com/highlightjs/cdn-release/blob/11.11.1/build/languages/scheme.min.js
SHA-256: b16f50dbe365947bdc670369a4bf079bfea2804a09e4b9e89c0faa87fd7f46d8
Uses the same bundled highlightjs-LICENSE.

LeftBlank Preview additionally bundles Sparkle 2.10.0 for software updates (MIT).
https://github.com/sparkle-project/Sparkle/tree/2.10.0
Sparkle and its external component notices are in Licenses/Sparkle-LICENSE.txt.
The framework is not included in direct or App Store builds.

ZIPFoundation 0.9.20 (MIT)
https://github.com/weichsel/ZIPFoundation/tree/0.9.20
Used to extract digest-verified example books in-process on macOS and iPadOS.
See ZIPFoundation-LICENSE.

The macOS app additionally bundles the LeftBlank MCP helper built with rmcp 3.5.0
(Apache-2.0), the official Model Context Protocol Rust SDK.
https://github.com/modelcontextprotocol/rust-sdk
Its complete pinned dependency notices are in the macOS-only MCP-LICENSES.txt.
The helper and its dependencies are not part of the iOS app or Tinymist engine.
